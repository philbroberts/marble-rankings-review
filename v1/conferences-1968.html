Marbles by conference.

Conference games redistribute marbles within the same group; these lines move when marbles cross conference boundaries. Average per team makes conferences of different sizes comparable. All scoring, including overtime, is included.

All teams start at zero each season. Final points include overtime. Groups use each season’s verified conference membership; current realignment is not backfilled into earlier seasons. Conference averages include every modeled member, including teams with no games. These are summaries of team balances, not a separate ranking model.
